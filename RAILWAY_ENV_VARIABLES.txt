================================================
  ORDER NOTIFICATIONS (choose one or both)
================================================

--- TELEGRAM NOTIFICATIONS ---
  Get notified on Telegram when a new order comes in.

  TELEGRAM_BOT_TOKEN       123456789:ABCdef...  (from @BotFather on Telegram)
  TELEGRAM_CHAT_ID         your numeric chat ID  (from @userinfobot on Telegram)

  HOW TO SET UP TELEGRAM:
  1. Open Telegram → search for @BotFather → send /newbot
  2. Follow steps → copy the token → paste as TELEGRAM_BOT_TOKEN
  3. Open @userinfobot → send /start → copy your Id number → paste as TELEGRAM_CHAT_ID
  4. Send any message to your new bot first (to activate the chat)


--- EMAIL NOTIFICATIONS ---
  Get notified by email (Gmail) when a new order comes in.

  NOTIFY_EMAIL               your.gmail@gmail.com
  NOTIFY_EMAIL_APP_PASSWORD  xxxx xxxx xxxx xxxx  (Gmail App Password, NOT your regular password)

  HOW TO SET UP EMAIL:
  1. Go to myaccount.google.com → Security → 2-Step Verification (enable it)
  2. Then go to: myaccount.google.com/apppasswords
  3. App name: "Noor Store" → Create → copy the 16-character password
  4. Paste it as NOTIFY_EMAIL_APP_PASSWORD


================================================
  HOW TO ADD THEM IN RAILWAY:
  1. Open your Railway project
  2. Click your service
  3. Click "Variables" tab
  4. Click "+ New Variable"
  5. Add each variable above

  REQUIRED (minimum to run):
    DATABASE_URL, SESSION_SECRET, PORT, NODE_ENV

  RECOMMENDED:
    ADMIN_USERNAME, ADMIN_PASSWORD, PUBLIC_URL

  OPTIONAL (notifications):
    TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID
    or NOTIFY_EMAIL + NOTIFY_EMAIL_APP_PASSWORD
================================================
